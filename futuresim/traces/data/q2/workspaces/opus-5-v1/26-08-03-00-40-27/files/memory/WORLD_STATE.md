## Scoring math (IMPORTANT)
Brier Skill = 1 - Σ(p_i - y_i)^2 over listed outcomes + the true outcome.
- If true answer listed with prob p: score = 1 - (1-p)^2 - Σ_{others} p_i^2
- If true answer NOT listed: score = -Σ p_i^2  (negative!)
- Proper scoring: honest probabilities maximize. Expected score ≈ q^2 for single candidate w/ prob q.
- => ALWAYS submit on every question (expected value ≥ 0 if calibrated). Never leave blank.
- Don't over-spread: if unsure, use fewer outcomes with moderate probs; total mass should equal P(one of my listed is right).
